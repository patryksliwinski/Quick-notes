# 2026-10-30 — The coverage gate must not exclude the buggy surface; fakes must model silent empties, not only throws (issue #60)

- **Context:** Issue #60 — the test suite passed while real bugs existed. The Kover exclusions in `app/build.gradle.kts` covered exactly the unstable classes (`SafNoteStore`, `MainActivity`, screens, `receiver.*`, `tile.*`), so the 80% gate measured only the healthy core; `FailingNoteStore` only threw, while real SAF failure modes are silent (`null` cursor → empty list, `null` stream → `""`); no test reproduced the widget → `onNewIntent` → new-note wiring; `PendingSaveJournal` durability (commit vs apply) was untested.
- **Lesson:** A coverage gate that excludes the classes where bugs live is a health theater, and a fake that only throws cannot catch silent-empty bugs. Fix structurally: (1) narrow the Kover exclusions to what genuinely needs a device (Compose screens, `MainActivity`, widget/tile RemoteViews wiring) and pull everything else — `SafNoteStore` via a registered fake `ContentProvider`, widget/tile intent mapping, pure loader logic — into the gate; (2) move entry-point decision logic out of the activity into a pure function (`NewNoteIntentRouter.incomingNoteRequestFromIntent`) so widget tap / `onNewIntent` re-delivery / `ACTION_SEND` are unit-testable without an emulator; (3) add a silent-empty fake (`EmptyResultNoteStore`) alongside the throwing one and assert the repository surfaces `NoteError` instead of an empty list/`""`; (4) assert durability paths synchronously (a `SharedPreferences` wrapper that fails `apply()` on `record`).
- **Rule now:** `app/build.gradle.kts` excludes only `ui.MainActivity*`, `ui.*ScreenKt*`, `receiver.*Layout*`, `receiver.*Provider*`, `tile.*`. New device-only code must be added to that list with a reason, and its decision logic extracted into a testable pure class (as `MainActivity` → `NewNoteIntentRouter`). Storage fakes must cover both failure modes — throwing and silent-empty — with repository-level assertions on the surfaced `NoteError`. Covered by `NewNoteIntentRouterTest`, `SilentEmptyNoteStoreTest`, `WidgetNoteLoaderTest`, and the extended `SafNoteStoreTest`.
