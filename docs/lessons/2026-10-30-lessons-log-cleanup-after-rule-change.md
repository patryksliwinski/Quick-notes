# 2026-10-30 — Lessons log cleaned after the rule change (issue #50 follow-up)
- **Context:** Issue #50 changed the rule (PR #55) so a `docs/lessons/` entry is required only when a PR taught something non-obvious. The ~30 files produced under the old per-PR-required rule were never audited, so the log still carried checkbox-dump entries from the 2026-10-29 scaffold day.
- **Lesson:** When a rule changes, the artifacts produced under the old rule must be re-evaluated against the new one — otherwise the noise the rule was meant to eliminate stays in the log forever. Entries whose content is fully restated by current `AGENTS.md` / `docs/WORKFLOW.md` / `CONTRIBUTING.md` (process rules, sandbox setup, one-time CI fixes) carry no novel takeaway and were deleted along with their index rows. Entries with a real gotcha or decision (SAF crash/permission/document-URI lessons, widget layout traps, coverage-gate setup, release signing/notes, Kotlin 2.0 plugin, lint NewApi, FileObserver-on-SAF, and the 2026-10-30 feature lessons) were kept.
- **Rule now:** `docs/lessons/` is a high-signal log: only non-obvious lessons stay; process/workflow mechanics live in `AGENTS.md` / `docs/WORKFLOW.md` / `CONTRIBUTING.md`, not in per-PR lesson files. Removed in this cleanup: `2026-10-29-agent-self-review-no-human-gate.md`, `2026-10-29-ai-agent-pr-review.md`, `2026-10-29-ci-setup-android-action-moved.md`, `2026-10-29-empty-repo-pr-ordering.md`, `2026-10-29-lessons-as-directory.md`, `2026-10-29-release-version-bump-needs-pr.md`, `2026-10-29-sandbox-github-push-credentials.md`.
