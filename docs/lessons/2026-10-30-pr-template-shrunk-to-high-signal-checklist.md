# 2026-10-30 — PR template shrunk to a short high-signal checklist
- **Context:** Issue #51 — the ~30-checkbox PR template (Summary, Type, 5-step Verification with pasted outputs, 6 golden rules, Tests, Lessons, 4-item Agent self-review, Screenshots) was filled with boilerplate on recent PRs (#36–#44); the real safety nets are CI, the Kover coverage gate, and lint.
- **Lesson:** A hand-filled checklist that no workflow or merge rule consumes is a zero-value ritual. Keep only what a machine can't check: what & why, which verification commands ran, quick-path purity, sync-agnostic storage, strings externalized, and a lesson if there is one. The "Type" section (derivable from the conventional-commit title prefix) and the ritual self-review checkboxes were removed; self-review findings go to PR comments only when there are actual findings.
- **Rule now:** `.github/PULL_REQUEST_TEMPLATE.md` is the short checklist above; `docs/WORKFLOW.md` and `CONTRIBUTING.md` no longer require filling every template section. CI + Kover + lint remain the enforcement layer.
