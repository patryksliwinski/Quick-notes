# 2026-10-29 — No human review: the agent self-reviews, comments, then fixes
- **Context:** Issue #2 — remove the "review will be done by a human" note. The review machinery (static scan in `pr-review.yml` + Copilot review request + Mistral agent review via the GitHub App) already exists, so only the docs/workflow text and the posted comment needed changing.
- **Lesson:** The review step itself did not need to change — only who performs it. The expected per-ticket loop is: agent implements → agent self-reviews its own diff → agent pushes the review as comments on the PR/issue → agent addresses and fixes those comments in follow-up commits. Merge gate is CI green + no blocking automated findings + self-review comments resolved, with no human approval step.
- **Rule now:** `AGENTS.md`, `CONTRIBUTING.md`, `docs/WORKFLOW.md`, `.github/PULL_REQUEST_TEMPLATE.md` (new "Agent self-review" section), and the `pr.yml` posted comment all describe the agent self-review loop and contain no human-review references. The layered-review lesson (2026-10-29-ai-agent-pr-review.md) was updated to drop the human final gate.
