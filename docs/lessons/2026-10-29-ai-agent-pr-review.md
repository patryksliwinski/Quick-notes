# 2026-10-29 — PR review is layered: fast static gate + AI agent review (no human gate)
- **Context:** Repo workflow setup (PR #1) — the user asked whether review could be done by an AI agent instead of only a static scan. Later updated (issue #2) when the user confirmed there is no human in the loop.
- **Lesson:** Yes, in layers. (1) The `pr.yml` static scan stays as a fast, deterministic gate (golden-rule grep; the Gradle checks run in the same workflow's build job). (2) The same workflow requests a Copilot AI review on every PR (`pulls.requestReviewers` with `copilot`). (3) A Mistral agent (Vibe) reviews the actual diff against `AGENTS.md` and posts a formal review via the GitHub App; the implementing agent then self-reviews, pushes its review as comments, and fixes them. There is no human review gate. Layer (1) catches mechanical failures instantly; layers (2)/(3) catch semantic issues.
- **Rule now:** `pr.yml` requests the Copilot reviewer after checks; `docs/WORKFLOW.md` documents the layers and the agent self-review loop. Review findings that change behavior get a lesson file in this directory.
